# 考勤统计

财务用的考勤统计网页应用。当前默认版本 **v2.0**：平时随时记录请假 / 出差 / 签到，月底导入刷卡记录后自动核算迟到、缺勤与罚款。

> **版本入口**
> - **v2.0（当前正式版）**：https://jhqz12.github.io/attendance-stats/
> - **v1.0-final（旧版，永久保留，可随时打开）**：https://jhqz12.github.io/attendance-stats/v1/
> - 源码 tag：`v1.0-final`（1.0 定稿）、`v2.0-books`（账本测试版）、`v2.0`（本次正式版）。
> - ⚠️ 两个版本的浏览器本地数据互相独立，不会共用；v2.0 的多月份账本数据不能倒回 v1.0 使用。

## 功能

- **两阶段使用**：打开就是当月考勤总表，平时随时点格子记请假、记出差、点日期表头一键签到；不自动判缺勤、不算罚款。月底导入刷卡记录后才按真实打卡时间核算迟到几分钟、缺勤与罚款金额，平时手工记录全部保留且优先级最高。
- **月份账本**：每月独立保存，记录中 / 待汇总 / 已归档三种状态，归档只读；可新建、切换、删除单月，JSON 备份与恢复。
- **导入打卡记录**：支持 .xls / .xlsx，数据只在本地浏览器处理，不上传。
- **自动判定**：迟到、上午/下午缺勤、早退、全天缺勤，按部门、上下班时间、费率自动计算罚款。
- **人工核实**：逐条核实，支持「直接核实」或「选原因核实」，核实后可一键撤销。
- **考勤总表**：整月每天上/下午出勤状态一览，每个格子可点击修改，支持手动同步到罚款明细。
- **出差登记**：多人多选批量登记，出差地 + 备注，自动联动考勤总表。
- **节假日/轮休**：周日轮休（A/B/C/D 组）、法定节假日黄色标记，可自定义具体日期。
- **导出**：罚款明细、个人汇总、考勤总表、出差登记，共 4 类表，支持 Excel / PDF。

## 使用方法

**方式一：在线使用（推荐）**

打开 https://jhqz12.github.io/attendance-stats/ 。第一次打开就自带完整员工名单，直接开始记录；月底点「导入打卡记录」上传刷卡表即可汇总。

**方式二：本地打开**

下载 `考勤罚款统计.html` 和 `xlsx.full.min.js` 两个文件放在同一文件夹，双击 `考勤罚款统计.html` 即可用。

> 数据保存在你自己浏览器的本地存储（localStorage）里，不会上传到任何服务器。换电脑、换浏览器、清站点数据都会丢数据，请定期点「⬇ 备份」导出 JSON，换设备后用「⬆ 恢复」导入。
