# 考勤统计

> 给财务用的浏览器端考勤核算工具：**平时随时记请假 / 出差 / 签到，月底导入员工刷卡记录后自动核算迟到、缺勤与罚款。**
>
> 当前版本 **v2.0.1** · 单文件网页，免安装、免服务器 · 数据只存在你自己的浏览器里 · 支持 Excel / PDF 导出

---

## 先理解一件事：到岗 ≠ 打卡

这个工具把一个月分成**两个阶段**，这是它和旧版 1.0 最大的区别：

| | 阶段一 · 平时记录 | 阶段二 · 月底汇总 |
| --- | --- | --- |
| 什么时候 | 每天，随发生随记 | 发薪前，导入完整刷卡记录后 |
| 记什么 | 谁请假、谁出差、谁到岗了 | 每个人**几点几分**打的卡 |
| 能不能算罚款 | **不能**，也不假装能算 | 能，按真实打卡时间算 |
| 页面长什么样 | 一打开就是当月考勤总表，全宽铺满 | 恢复两栏，罚款明细在前、考勤总表在最后 |
| 罚款明细 | 收起成一条「待导入」说明 | 自动列出迟到、缺勤、早退和金额 |

「今天谁来了」和「今天谁几点打卡、有没有迟到」是两套评判标准。平时的人工记录只是方便随时看个大概，**不能代替打卡记录**，也**永远不会参与罚款计算**；月底由刷卡记录统一核算，平时记的请假、出差一条不丢，且优先级最高。

## 2. 第一次打开：5 分钟上手

### 2.1 打开就是总表，不用先导入

第一次打开会直接进「平时记录」界面，**自带 26 人内置名单**（6 位免打卡高层 + 20 位普通员工，工号、部门、休息组都已填好），不用先导入打卡表、不用先加人。

万一花名册被清空，会看到双入口欢迎页，点「✎ 直接开始记录（不导入）」即可；也可以直接把 `.xls / .xlsx` 拖进页面导入。

### 2.2 认识记录阶段的极简视图

为了让红框总表铺满一屏，记录阶段**故意藏起了**标题、账本栏、概览卡片、罚款明细、同步条和总表标题，只剩：

- 顶栏一行小按钮：`📒 月份 / 备份` · `导入打卡记录` · `⚙ 展开设置` · `↶ 撤销` · `导出中心` · `导出完整统计`
- 一行目录：`📋 考勤总表` → `✈️ 出差登记`
- 统计列显示/隐藏勾选框
- **当月考勤总表**（字号与格子都放大过）

需要调设置、加人、改轮休时点 `⚙ 展开设置`，再点一次收起；需要切月份、备份时点 `📒 月份 / 备份` 临时展开账本栏（导入打卡记录后的汇总阶段，账本栏本来就常显）。

**记录阶段的设置栏只显示和记录有关的四块**：周日轮休、节假日休假、员工管理、考勤总表设置。迟到规则、罚款费率、下班时间、加班、核实方式这些**判定类参数整块隐藏**，等导入打卡记录后才自动出现 —— 平时不看它们，界面才不臃肿。

### 2.3 直接点格子记请假

考勤总表每人每天分「上 / 下」两格。点一下格子，符号按「出勤 → 轮休 → 请假 → 缺勤 → 出差」循环切换，点几次就到想要的状态。

| 符号 | 含义 | 颜色 |
| --- | --- | --- |
| `√` | 出勤 | 绿 |
| `○` | 轮休 / 休息 | 蓝（法定节假日显示**黄色圆圈**） |
| `×` | 请假 | 红 |
| `缺` | 缺勤 | 橙 |
| `差` | 出差 | 紫 |

符号和含义可以在「考勤总表设置 → 考勤标记」里增删、改符号、改文字、换颜色。

### 2.4 表头就是「一键签到」按钮

**直接点表头上的日期数字（1、2、3…）= 当天全员签到，再点一下 = 取消当天全员签到。** 已签到的日期格会变淡绿并带一个小 ✓，没有多余工具条。

- 轮休、节假日的人自动标 `○`，不会被误标成出勤；
- 已经手工记了请假 / 出差的人**不会被冲掉**；
- 取消只清掉当天由一键签到生成的草稿，人工改过的格子一律保留；
- 表头标题写着「只记到岗，不代替打卡与罚款核算」—— 签到草稿在**导入刷卡记录时会自动清掉**，由真实打卡时间重新判定，绝不盖住迟到或缺勤。

### 2.5 记出差

点「＋ 添加出差」→ 弹窗里可**按姓名或部门搜索、多选人员**（有全选 / 清空）→ 点选多个日期 → 填出差地和备注（都可留空）→ 点「登记」。

登记结果自动汇总进「出差登记表」，并联动考勤总表把该人该天标成 `差`；表里可以直接改出差地、备注、显示/隐藏备注列、按部门筛选、清除某人记录。

### 2.6 撤销

顶栏 `↶ 撤销` 可回退最近一次操作（改格子、一键签到、核实、改轮休、调换分组、删员工等）。撤销栈**只在本次会话、当前账本内有效**，切换月份会清空，避免误撤销到别的月份。

## 3. 月底汇总：从导入到导出

### 3.1 导入员工刷卡记录

点顶栏「导入打卡记录」，或直接把文件拖到页面上。支持 `.xls` / `.xlsx`，**数据只在本地浏览器解析，不上传服务器**。

刷卡表格式要求（沿用你们仓库软件导出的原表即可）：

- 读取**第一个 sheet**；
- 前 6 行里要有类似 `2026-10-01～2026-10-31` 的日期区间，用来识别**这份表属于哪一年哪一月**；
- 每个员工是一个块：块首行的第 5 / 11 / 23 列（Excel 的 **E / K / W 列**）分别是 `工号：`、`姓名：`、`部门：`；
- 块首行的下一行是**日号**（1–31 的数字）；
- 再往下是每天的刷卡时间，一个格子里可以有多个时间点（如 `09:05 18:32`）。

**按年月自动路由**：如果文件的年月和当前打开的账本不一致，会弹窗问你要不要切到对应月份账本再导入；不会把 10 月的数据倒进 11 月。当前月份已记录的内容不受影响。

### 3.2 导入后自动发生什么

1. 平时记的**请假、出差、核实、节假日、轮休全部保留**，优先级最高；
2. **一键签到的草稿自动清掉**，让打卡时间接管判定；
3. 打卡表里出现的新人自动并入名单并记进花名册；
4. 自动算出迟到、上午/下午缺勤、早退、全天缺勤和罚款金额；
5. 页面**自动切回汇总排版**：左栏设置恢复常显、判定类参数出现、顺序变成「罚款明细 → 出差登记 → 考勤总表」，总表字号恢复原样、一键签到栏隐藏。

### 3.3 判定规则与默认值

「参数设置」里的值改完即时重算，且**跨月份共用**。默认值如下：

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| 早上打卡截止 | 09:00 | 超过即迟到 |
| 迟到费率 | 1 元/分钟 | 迟到金额 = 分钟 × 费率 |
| 迟到 ≥ N 分钟算上午缺勤 | 30 分钟 | 达到阈值直接按半天缺勤，不再按分钟罚 |
| 下午上班截止 | 14:00 | 只有下午卡时用来判断上午是否请假 |
| 下午迟到费率 | 1 元/分钟 | 同上 |
| 下午迟到 ≥ N 分钟算下午缺勤 | 30 分钟 | 达到阈值按上下午均缺勤 |
| 上午缺勤（半天） | 开 | 按**每个人自己的半天工资**计算 |
| 下午缺勤（半天） | 关（可开） | 同上 |
| 早退 | 关（可开），1 元/分钟 | 按部门下班时间判断 |
| 全天缺勤 | 半天工资 × 2 | 上下班都没打卡 |
| 下班打卡时间 | 财务部 18:00 / 其他部门 19:00 | 导入后按部门列出，可逐个改 |
| 加班统计 | 关（可开），起点 20:00 | 下班卡晚于起点才计加班 |
| 核实方式 | 一键核实 | 可改「选原因核实」 |

特殊规则：

- **免打卡人员（高层）不参与罚款判定**，出勤状态在总表里手动维护；
- **外勤 / 送货**人员不打下班卡视为正常；
- 全体休息日、轮休日、节假日一律不算缺勤；
- **没导入刷卡记录时，系统绝不判缺勤**（旧版曾把全员每天算成全天缺勤，2.0 已修）。

### 3.4 人工核实

罚款明细按「全部 / 迟到 / 早退 / 缺勤半天 / 全天缺勤 / 已核实」分页，每条都能核实：

- **一键核实**：点「✓ 免罚」直接取消该条罚款；
- **选原因核实**：下拉选具体原因，导出时会带上原因列，方便发给别人看。可选原因：`情有可原`、`出差`、`送货`、`收货`、`发货`、`请假`、`休息日/调休`、`正常上班(误报)`；
- 核实过的行会淡出，可「撤销」恢复；单独改过金额的半天记录也保留。

总表上的手工标记如果要回写到罚款明细，点 `⇅ 同步到罚款明细`（**手动同步**，不会自动覆盖你的核实结果；未导入打卡记录时按钮置灰）。

### 3.5 导出

**导出中心**：4 类表，各支持 Excel（可编辑）和 PDF（美观打印）。

| 表格 | 内容 |
| --- | --- |
| 罚款明细 | 按人分组的违规记录、说明、金额 |
| 个人罚款汇总 | 每人的迟到 / 上午缺勤 / 下午缺勤 / 早退 / 全天缺勤 / 合计 |
| 考勤总表 | 整月每天上下午状态 + 统计列 |
| 出差登记表 | 出差地、人员、日期、备注 |

**导出完整统计**：一个 `.xlsx`，含 6 个 sheet —— 个人汇总、罚款明细、已核实记录、每日明细（工号 / 姓名 / 部门 / 日期 / 上班卡 / 下班卡 / 判定 / 说明 / 罚款）、考勤总表、出差登记表。

两点细节：

- **PDF 是打开浏览器打印窗口**，在打印对话框里选「另存为 PDF」，所以需要允许本站弹窗；
- **导出是给所有人看的**：导出文件里姓名一律普通黑色、不带「免打卡」标注；编辑界面里的绿色姓名只是给自己看的编辑态提示，不会带进导出文件。

## 4. 月份账本

### 4.1 三种状态

| 状态 | 含义 | 能否编辑 |
| --- | --- | --- |
| 记录中 | 平时随发生随记 | 可以 |
| 待汇总 | 打卡记录已导入或准备导入，等待核算 | 可以 |
| 已归档 | 工资已结算 | **只读**：格子、表头签到、导入、撤销、改设置都会被拦。点顶部「解锁继续编辑」回到待汇总 |

状态在账本栏的「当前状态」里点一下即可切换，归档前会二次确认。

### 4.2 常用操作

| 操作 | 入口 |
| --- | --- |
| 新建月份 | `📒 月份 / 备份` → `＋ 新建月份`（默认带出下个月，自动带入花名册与默认轮休） |
| 切换月份 | 点月份标签 |
| 删除整月 | 月份标签右侧 `×`，**不可逆、二次确认**，会列明该月打卡明细 / 请假 / 出差 / 签到 / 核实一起删除；删当前月会自动回到当月，不会白屏 |
| 备份 | `⬇ 备份` → 导出全部账本 JSON |
| 恢复 | `⬆ 恢复` → 选 JSON，**会覆盖当前全部账本与设置**，需确认 |
| 打开默认进入 | 账本栏下方下拉：当月 / 上次打开的月份 / 待汇总月份 |

**导出备份之后**会问一句「检测到 N 份已归档月份，要不要从本地缓存清掉？」—— 只删已归档，记录中 / 待汇总一律不动，点取消全保留。请确认 JSON 已下载成功再点确认。

### 4.3 每份账本独立保存什么

每份账本各自隔离：名单、打卡明细、手工勾选、核实记录、出差地/备注、节假日、轮休日期、一键签到状态。

**跨月份全局共用**：参数设置、员工花名册、考勤标记、高亮配色、统计列开关。

> 删除员工只从**当前月份**移除，不影响其他月份；新增员工自动记进花名册，下个月自动带入。
> 对不上姓名的人会在导入时自动并入对应月份账本。

### 4.4 缓存容量（按真实数据实测）

| 内容 | 占用 |
| --- | --- |
| 全局固定部分（26 人花名册 + 设置 / 标记 / 配色） | ≈ 3 KB，不随月份增长 |
| 单月打卡明细（20 人 × 483 天 × 2 个时间点） | ≈ 7 KB |
| 平时全员签到一个月（26 人 × 30 天） | ≈ 42 KB |
| 一个月实际 | 8 KB（只存打卡）～ 50 KB（天天签到） |

浏览器 localStorage 一般 5 MB（部分 10 MB）→ 约 **100 个月 / 8 年**（10 MB 约 200 个月 / 17 年）。容量不是瓶颈，**真正的风险是缓存跟着浏览器和网址走**：清站点数据、无痕模式、换设备都会变空。

万一缓存写满，提示会指引你走真实可操作的路径：`⬇ 备份` 导出 JSON → 月份标签 `×` 删不用的旧月份（优先已归档）→ 重新做刚才的操作 → 需要时用 `⬆ 恢复` 导回。

## 5. 员工与休息组

### 5.1 员工管理

点 `⚙ 展开设置` → 「员工管理」，可增删人员、改属性：

| 列 | 作用 |
| --- | --- |
| 姓名 | 显示工号（有则括号附注） |
| 免打卡 | 高层开关，打开后不参与罚款判定，总表手动维护 |
| 半天工资 | 扣半天 / 全天薪资的基数，逐人设置 |
| 部门 | 决定下班打卡时间（财务部 18:00 / 其他 19:00），也用于出差表筛选 |
| 外勤 | 不打下班卡视为正常 |
| 休息组 | A / B / C / D / 不休 |
| 删 | 只从当前月份移除 |

另有 `＋ 添加员工`、`自动推算 A/B 组`（根据导入的打卡记录里周日到岗规律推算）两个按钮。

**内置名单**：26 人（6 位免打卡高层 + 20 位普通员工），来自用户提供的 2026-10 打卡记录，含工号、部门、休息组。新电脑 / 新浏览器第一次打开也自带，不用先导入。名单可在员工管理里随时改；老缓存会在打开时自动补齐缺失人员（已导入打卡的月份不动，避免补出假缺勤）。

### 5.2 休息组规则

| 组别 | 默认休息日 |
| --- | --- |
| A 组 | 第 1 / 3 / 5… 个周日 |
| B 组 | 第 2 / 4… 个周日 |
| C 组 | 每周日休（可切「双休」= 周六 + 周日） |
| D 组 / 不休 | 不休 |

- 「周日轮休」卡片里**点每个日期**可在「A 休 → B 休 → 不休」间循环，方便调休；
- `⇄ 调换 A / B 组人员` 只交换员工管理里两组的人，不改轮休日期，可撤销；
- 「节假日休假」里点选放假日期（国庆、春节等），总表显示黄色圆圈、**全员休息**，再点一次取消；
- 总表标题会自动显示「`YYYY年M月 考勤总表 · 应出勤 N 天（本月共 X 天，休 Y 天）`」。

## 6. 考勤总表：符号、统计列、个性化

- **统计列**（右侧汇总，可逐个显示/隐藏）：出勤、请假、扣款、加班、午餐、出差。默认开启出勤 / 请假 / 扣款 / 加班 / 出差，**午餐默认关闭**；每个半天格按 0.5 天计。
- **十字悬浮高亮**：鼠标停在任意格或表头上，整行、整列、上下表头一起高亮，方便横向看人、纵向看日期。考勤区与统计列**可分别设主题色**，内置 9 组浅色（清透浅蓝、浅薰衣草紫、薄荷浅青、暖浅杏、沉稳浅蓝、淡蜜桃、浅桃奶霜、浅裸棕、浅蜂蜜奶），默认考勤区 `#CCE8FB`、统计列 `#DEE9F5`。
- **自定义考勤标记**：符号、含义文字、颜色都可增删改，改完会同时影响格子点击的循环顺序和显示。
- **冻结姓名列**：横向滚动时姓名始终可见。
- 表头带月份、星期、上/下午；目录导航会跟着当前阶段自动调整顺序。

## 8. 常见问题

**Q：换电脑 / 新浏览器打开，我记的数据没了？**
数据存在「浏览器 + 网址」的 localStorage 里，不跟着账号走。在旧设备点 `⬇ 备份` 导出 JSON，新设备点 `⬆ 恢复` 导入即可。内置 26 人名单是写在代码里的，所以新设备打开人还在，只是手工记录需要搬。

**Q：为什么没有罚款明细 / 一片空白？**
那是「平时记录」阶段，还没导入刷卡记录。系统刻意不判缺勤，避免凭空算出满屏假罚款。导入后自动出现。

**Q：一键签到会不会让人免掉迟到罚款？**
不会。签到只记「到岗」，带 `draft` 标记，**导入刷卡记录时自动清除**，由打卡时间重新判定。它不参与罚款、也不会被同步成「误报免罚」。

**Q：导入后某人显示「缺勤」，但他其实请假了？**
先在总表把该天改成 `×`，或在罚款明细里核实为「请假」。手工记录优先级最高，核实后该条罚款取消并带原因导出。

**Q：导错了月份怎么办？**
导入时会按文件里的日期区间识别年月并询问是否切到对应账本。真导错了，用月份标签 `×` 删掉那个月账本（先备份），再重新导入一次；平时记的内容在其他月份不受影响。

**Q：归档之后改不了？**
点顶部橙色提示条里的「解锁继续编辑」，状态回到「待汇总」即可改，改完可以再归档。

**Q：缓存满了 / 提示保存失败？**
按提示：`⬇ 备份` → 用月份标签 `×` 删旧月份（优先已归档）→ 重做刚才的操作。按实测容量，正常使用十几年都不会满。

**Q：能回到 1.0 吗？**
能，1.0 有独立永久入口 `/v1/`。源码 tag `v1.0-final` 也一直在。但两版网址与数据结构不同，**2.0 的账本数据不能倒回 1.0 使用**。

**Q：两个网址的数据能合并吗？**
不能自动合并。请固定用其中一个记录；要搬就用 JSON 备份 / 恢复，注意恢复会**覆盖**目标网址里现有的全部账本。

## 9. 数据、隐私与浏览器要求

- **不上传**：所有解析、判定、导出都在这个浏览器里完成，页面没有后端接口，数据不会发到任何服务器。
- **存哪里**：`localStorage`，键名 `kaoqin_fakuan_v1`；清空站点数据 / 无痕模式 / 换设备都会丢，靠 JSON 备份搬运。
- **源码里有什么**：内置 26 人默认名单仅含工号、姓名、部门、休息组（来自用户提供的 2026-10 打卡记录），**不含真实打卡时间、工资数额或罚款结果**；真实的 `考勤罚款统计_2026-10.xlsx` 数据文件没有上传仓库。工资基数默认是 50，请在员工管理里按实际填写。
- **浏览器**：Chrome / Edge / QQ 浏览器等现代浏览器；需允许 localStorage；导出 PDF 需允许弹窗。
- **离线使用**：下载 `考勤罚款统计.html` 与 `xlsx.full.min.js` 放在**同一个文件夹**，双击 html 即可，无需联网、无需安装。注意本地文件又是一份独立缓存。
