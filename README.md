# 考勤统计

财务用的考勤统计网页应用：导入刷卡记录 → 自动判定迟到/早退/缺勤 → 人工核实 → 一键导出。

## 功能

- **导入打卡记录**：支持 .xls / .xlsx，数据只在本地浏览器处理，不上传。
- **自动判定**：迟到、上午/下午缺勤、早退、全天缺勤，按部门、上下班时间、费率自动计算罚款。
- **人工核实**：逐条核实，支持"直接核实"或"选原因核实"，核实后可一键撤销。
- **考勤总表**：整月每天上/下午出勤状态一览，每个格子可点击修改，支持手动同步到罚款明细。
- **出差登记**：多人多选批量登记，出差地 + 备注，自动联动考勤总表。
- **节假日/轮休**：周日轮休、法定节假日黄色标记，可自定义具体日期。
- **导出**：罚款明细、个人汇总、考勤总表、出差登记，共 4 类表，支持 Excel / PDF。

## 使用方法

**方式一：本地打开**（推荐日常使用）

下载 `考勤罚款统计.html` 和 `xlsx.full.min.js` 两个文件放在同一文件夹，双击 `考勤罚款统计.html` 即可用。

**方式二：在线使用**

访问 GitHub Pages 地址（见仓库首页右侧 About 区域的链接）。

> 数据保存在你自己浏览器的本地存储（localStorage）里，不会上传到任何服务器。换电脑或清浏览器缓存会丢数据，请及时导出备份。
